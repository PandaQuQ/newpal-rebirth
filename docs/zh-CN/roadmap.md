# 路线图与现状

早期预览，还很粗糙，有不少细节仍是猜测。本页尽量如实说明哪些是猜的。

## 现在能用的（`main`）

- 原地读取原版数据：索引包、LZO、RLE 精灵、LMF 地图、ACT 表、对话脚本、数值表。
- 游戏目录检测（参数、环境变量、配置、Steam 自动检测、选择目录窗口）和校验。
- 带深度遮挡的地图、8 方向行走、A* 点击寻路、区域触发、场景切换。
- 从 `maps.dat` 读取 NPC 及其对话脚本，对话框，虚拟机里的剧情标记、变量和跳转。
- 通过 `rodio` 播放场景音乐和脚本音效。
- 35 ms 逻辑拍，按显示器刷新率渲染并插值；高清静帧或着色器放大。
- 模组 VFS，UTF-8 的 i18n、语言包和运行时切换，`newpal-i18n` 工具。
- 残差补丁的构建和应用工具（`newpal-patch`）。

## 进行中（`modern-ui` 分支，未合并）

- 用 `vello` 做的矢量界面：启动器、标题、设置、读档、暂停，以及原版风格的对话框和系统菜单。

## 还没做的

- **没有存档系统。** 界面分支里有“继续 / 读档”，但没有东西可读。
- **没有战斗，没有背包**（脚本目前看到的是空背包），没有商店。
- 系统菜单的子界面：物品、装备、法术、状态、存档，目前只显示“尚未完成”的提示。
- 战斗界面和商店界面。
- 对话框位置：原版把框放在说话角色旁边，并按文字大小定尺寸；我们固定放在屏幕底部。
  对话框的边框图、头像、精确的配色和打字速度档位都是近似的。`<glyph>` 控制码的含义尚未确认。
- NPC 移动和隐藏角色（op 0x11）、“上一个场景”目标，以及很多过场动画的操作码。
- 菜单背景是本项目自己画的水墨替代图，不是原版画作。
- 音量变化只在开始播放时生效。改分辨率后没有“是否保留设置”的倒计时。`Config::save_to` 会丢掉 `[display]`、
  `[audio]` 和 `[input]` 表（`modern-ui` 上的已知问题）。
- 完整高清补丁的全量计时和全量 PSNR 复验。
- 只在 Windows（GNU 工具链）上测试过。

## 值得知道的猜测

踏上脚本号 >= 6000 的格子会立即触发，其他的需要按动作键；角色号 >= 699 不可见；音乐模式 2 表示只播放一次；
主角锚点在底部居中。这些在测试中与原版一致，但来自对行为的观察，而不是规格文档。
